# NRB 차량 렌탈현황

회사 차량 렌탈 계약 현황을 Excel 파일로 생성하는 스크립트입니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `create_car_excel.py` | 차량 렌탈현황 Excel 파일 생성 스크립트 |
| `차량_렌탈현황_변경.xlsx` | 생성된 Excel 결과물 |

## 사용법

```bash
pip install openpyxl
python create_car_excel.py
```

## 주요 내용

- 총 17대 차량 렌탈 현황 관리 (200호2725 오진택 계약해지로 1대 제외)
- 변경된 차량(서울공용2, 200호3807)은 노란색으로 표시
- 보증금, 월 렌트료, 기타비용, 총계 자동 합산
